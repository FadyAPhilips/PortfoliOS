# Settings, Welcome notice and favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Display Properties program that switches text-size presets (chrome included), font style, desktop colour, Welcome-on-startup and reduced motion; a desktop-browser notice on Welcome; a CRT favicon.

**Architecture:** A pure preset table (`src/os/settings.js`) turns the visitor's settings into CSS custom properties and chrome heights. A `SettingsProvider` above the window manager writes those properties to `<html>`, persists committed fields to `localStorage`, and feeds the live title-bar/taskbar heights to the geometry code. Every font size in the CSS becomes a role-named variable whose Default value is today's literal.

**Tech Stack:** Vite + React 19 (JSX), plain CSS, 98.css 0.1.21, vitest.

**Spec:** `docs/superpowers/specs/2026-11-17-settings-design.md`

## Global Constraints

- Default text size + Classic font must render **pixel-identical** to today.
- Presets only: `small | default | large | xlarge`, scale `0.9 | 1 | 1.25 | 1.5`, title bar `20 | 22 | 26 | 30` px, taskbar `26 | 28 | 32 | 36` px.
- Icons never scale (16px, 32px, 13px title-bar glyphs stay put); containers grow around them.
- Exempt from scaling: `.wallpaper-name` / `.wallpaper-tagline` (108/42, compact 36/16), `.welcome-word` / `.welcome-to` (28/16, narrow 22). They stay literal.
- Font style switches only the system font: not MySpace's page body (Arial), not Notepad (Fixedsys), not `.wallpaper-text`. `.ms-chrome` *does* switch.
- Storage key `portfolios.settings`; store **only committed fields**; every storage access in try/catch; failure → defaults.
- All copy in `src/content/*.json`; approved strings below are verbatim.
- Chrome styles reference `:root` tokens, never hex (CLAUDE.md convention).
- No geometry code may import `TITLEBAR_H` / `TASKBAR_H` for live values.

## Review Focus

1. **Storage blocked or throwing** (Safari private mode, cookies off): site boots at defaults, Settings still applies for the session, nothing crashes. → Task 1 `parse` tests; Task 3 manual check with `localStorage` stubbed to throw.
2. **Stale or hand-edited stored blob** (unknown preset id, wrong types, extra keys): each bad field falls back alone, good fields survive. → Task 1 tests.
3. **Extra Large on a narrow or compact (<768px) screen**: taskbar buttons, Start menu rows, title bars and desktop icon labels grow without clipping; the desktop height excludes the taller taskbar so maximized windows don't hide under it. → Task 3 click-through at 1024×700 and 390×844.
4. **Changing preset with a maximized window open**: it refits to the new desktop height immediately. → Task 3 click-through.
5. **Apply then Cancel**: Cancel discards only what wasn't applied; already-applied settings stay; untouched Reduce motion is never written. → Task 1 `changedFields` tests; Task 4 click-through checking `localStorage`.

### Task 1: Pure settings module

**Files:**
- Create: `src/os/settings.js`
- Test: `src/os/settings.test.js`

**Interfaces:**
- Produces:
  - `STORAGE_KEY = 'portfolios.settings'`
  - `TEXT_SIZES: Array<{ id, scale, titlebarH, taskbarH }>` in order small, default, large, xlarge (values from Global Constraints)
  - `FONT_STYLES: Array<{ id: 'classic'|'smooth', family: string, smoothing: 'none'|'auto' }>` — classic family `'Pixelated MS Sans Serif', Tahoma, 'Segoe UI', sans-serif`; smooth `Tahoma, 'Segoe UI', Verdana, sans-serif`
  - `DESKTOP_COLORS: Array<{ id, hex }>` — `teal: #008080` first, plus black, navy, darkgreen, maroon, purple, slate (hexes builder's)
  - `FONT_TOKENS: Record<string, number>` — Default px by role: `ui: 11, heading: 13, startBanner: 15, mono: 12, web: 11, webName: 14, webBanner: 12, webCaption: 10`
  - `BASE_LABEL_W = 75` (desktop/Explorer icon label width at Default)
  - `DEFAULTS = { textSize: 'default', fontStyle: 'classic', desktopColor: 'teal', showWelcome: true }` (no `reduceMotion` — it's environmental)
  - `parse(raw: string | null): Partial<Settings>` — never throws
  - `resolve(stored: Partial<Settings>, env: { prefersReducedMotion: boolean }): Settings` — `{ ...DEFAULTS, reduceMotion: env.prefersReducedMotion, ...stored }`
  - `changedFields(current: Settings, staged: Settings): Partial<Settings>` — only keys whose values differ
  - `chrome(settings): { titlebarH: number, taskbarH: number }`
  - `cssVars(settings): Record<string, string>` — keys `--fs-<token>` (kebab-case, e.g. `--fs-start-banner`), `--titlebar-h`, `--taskbar-h`, `--label-w`, `--font-ui`, `--font-smoothing`, `--desktop-teal`; sizes `Math.round(base * scale) + 'px'`
  - `Settings = { textSize, fontStyle, desktopColor, showWelcome: boolean, reduceMotion: boolean }`
